# 12-prompt hardening bench — code-weighted (fusion's weak spot) + math + design + concept
# code
Implement an LRU cache with TTL in Python without functools; include Big-O per operation.
Write a thread-safe bounded blocking queue in Python (no queue.Queue); explain the invariants.
Implement Dijkstra's shortest path in Python with a binary heap; state complexity and edge cases.
Debug and fix: a Python asyncio producer/consumer that deadlocks under backpressure. Show corrected code.
# math / reasoning
Prove or disprove: every bounded monotone sequence of real numbers converges. Rigorous but concise.
Prove the halting problem is undecidable. Keep it self-contained and precise.
Given 3 six-sided dice, what is the probability the sum is at least 15? Show the counting.
# system design
Design a rate limiter for a distributed API gateway: token bucket vs sliding window log, pick one, justify, sketch the data model.
Design an idempotency layer for a payments API so retried requests never double-charge. Cover storage and edge cases.
Design a URL shortener that scales to 1B links: key generation, storage, cache, collision handling.
# concept / explanation
Explain how a Mixture-of-Agents system can outperform its strongest member, and when it cannot.
Explain the CAP theorem and why "CA" systems are effectively a myth in real distributed systems.
